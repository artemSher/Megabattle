# Megabattle

Проект Megabattle - веб-приложение, разработанное с использованием современных технологий.

## Технологии

- React
- TypeScript
- SCSS
- Webpack

## Установка

1. Клонируйте репозиторий:
```bash
git clone git@github.com:lilsher/Megabattle.git
```

2. Установите зависимости:
```bash
npm install
```

## Разработка

Для запуска проекта в режиме разработки:
```bash
npm start
```

## Сборка

Для создания production-сборки:
```bash
npm run build
```

Собранные файлы будут находиться в директории `dist/`.
